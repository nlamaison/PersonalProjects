## Simple Planner
**WIP**
The goal of `Simple Planner` is to compare traditional sampling-based motion planning algorithms to a relatively simple learned model in a 2D, fixed world state simulation environment. 

This project will (soon, hopefully, someday) implement _all_ of: 
- stochastic, sampling-based path finding algorithms
- classic graph search algorithms
- a machine-learned step-wise action path finding model
- an interactive tool for demonstrating step-wise actions towards a goal configuration, to be used as data for model training
- a simulation environment
- a suite of motion planning metrics
- a workflow to run a large number of path finding simulations using traditional and learned methods, compare their performances, and generate a report with statistical metrics

I started this project with the goal of refreshing the core/traditional robotics skills I picked up while in graduate school and working at my first internship.
